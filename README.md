# Legit Assets — Steam Mini App для Vercel

Готовий код мініаппу з компактним синім оформленням, каталогом конкретних оголошень LolzTeam, кошиком і цінами у гривнях та доларах. Мову визначає адреса: `/uk/`, `/ru/`, `/en/`.

## Що змінилося

- Повернуто компактний формат початкового мініаппу: ширина до 720 px, сині скляні картки, вибір гри, закріплена нижня панель кошика. Великий рекламний екран прибрано.
- У кожній картці, деталях і кошику видно обидві валюти. Перемикач UAH/USD визначає основну валюту, валюту цінових фільтрів і оформлення. Вибір запам'ятовується.
- **Націнка — 20%**, як обрано. Вона застосовується на сервері, а не в браузері.
- Курси завантажуються автоматично з ExchangeRate-API Open Access. Джерело оновлює їх щодня; сервер кешує до наступного оновлення. За наявності Redis кеш спільний між інстансами Vercel.
- Підключено Telegram SDK: ready, expand, кольори, тактильний відгук, нативна кнопка «Назад» у модальних вікнах, відкриття бота через openTelegramLink.
- Додано Vercel Python Function, маршрутизацію `/api/*`, публічну папку `public/` і Redis для замовлень. На Vercel сервер ніколи не записує замовлення у локальний SQLite.

## Деплой на Vercel

1. Завантажте **весь вміст папки `legit-shop-steam-vercel`** у Git-репозиторій. На рівні його кореня мають лежати `vercel.json`, `server.py`, папки `api/` та `public/`.
2. Vercel → Add New Project → імпортуйте репозиторій.
3. Framework Preset: **Other**. Root Directory: корінь проєкту. Build Command та Install Command залиште типовими/порожніми. Output Directory: **public** — це вже задано у `vercel.json`.
4. Додайте серверні Environment Variables з таблиці нижче.
5. Для збереження замовлень додайте Upstash Redis через Vercel Marketplace / Storage та підключіть його до проєкту. Якщо інтеграція створила змінні з іншим префіксом, скопіюйте їхні значення у потрібні `UPSTASH_REDIS_REST_*`.
6. Зробіть Deploy. Відкрийте `https://ваш-домен.vercel.app/uk/`. Для перевірки конфігурації відкрийте `/api/config` — токенів у відповіді немає.
7. У BotFather задайте URL мініаппу/меню бота на цей HTTPS-домен. Для мовних кнопок використовуйте відповідно `/uk/`, `/ru/`, `/en/`.
8. Після зміни Environment Variables виконайте Redeploy, щоб функції отримали нові значення.

Не встановлюйте Root Directory у `public`: тоді Vercel не побачить сервер і конфігурацію API.

### Змінні середовища

| Змінна | Значення / призначення |
|---|---|
| `LZT_TOKEN` | Токен LolzTeam Market зі scope `market`. Потрібен для живих оголошень. |
| `MARKUP_PERCENT` | `20`. Можна змінити пізніше. Це націнка на закупівельну ціну, не маржа від продажу. |
| `DEMO_MODE` | `0` для роботи; `1` лише для перегляду вигаданих товарів. |
| `UPSTASH_REDIS_REST_URL` | HTTPS REST URL бази Upstash. |
| `UPSTASH_REDIS_REST_TOKEN` | REST token з правами читання/запису. Потрібен для замовлень на Vercel. |
| `TELEGRAM_BOT_USERNAME` | Username вашого бота без `@`. Увімкнути після реалізації обробника замовлень. |
| `BOT_API_SECRET` | Випадковий серверний секрет, спільний для бота і цього API. Це не токен Telegram-бота. |
| `TELEGRAM_BOT_TOKEN` | Рекомендовано для робочого мініаппу: токен того самого бота для перевірки підпису Telegram initData. Якщо заданий, оформлення поза Telegram або з простроченою сесією блокується. |
| `PUBLIC_ORIGIN` | Можна залишити порожнім: використовується поточний домен Vercel, включно з Preview. За потреби можна вказати точний `https://shop.example.com` без слеша в кінці. |

Всі токени задаються у Vercel, не в `public/app.js` і не в HTML. Файл `.env.example` містить лише шаблон. `.env` не публікуйте в Git.

Згенерувати `BOT_API_SECRET` локально:

```bash
python -c "import secrets; print(secrets.token_urlsafe(32))"
```

## Розрахунок ціни

Для кожної валюти використовується формула:

```text
Ціна продажу = ціна LolzTeam × курс цільової валюти / курс валюти джерела × 1.20
```

Курси беруться з одного знімка відносно USD. Обидві кінцеві ціни округлюються один раз до 2 знаків, а підсумок кошика складається з показаних цін. В браузері немає коефіцієнта націнки або курсу, яким можна підмінити суму оформлення.

Приклад **лише з тестовими курсами**: 1000 RUB при умовних 100 RUB/$ та 40 грн/$ → 12.00 USD або 480.00 грн після +20%. Це не поточний курс.

Цінові фільтри працюють за кінцевою ціною з націнкою. Сервер переводить межі назад у валюту пошуку LZT і додатково перевіряє округлену ціну результату. При зміні валюти тільки цінові межі скидаються з повідомленням.

Якщо курс недоступний чи дані старші за 48 годин, API повертає помилку. Сирі ціни в рублях не видаються як гривні/долари. Перед оформленням сервер перечитує товари й застосовує актуальні курси та націнку. Якщо кінцева ціна змінилася, потрібне повторне підтвердження.

## Оформлення і бот

Сайт формує замовлення за **вашою кінцевою ціною з націнкою** й передає його в бот через `start=order_<id>`. Замовлення зберігається в Redis; повтор одного запиту не створює другий запис навіть між різними інстансами Vercel.

На стороні бота потрібно обробити цей ID, отримати замовлення з захищеного endpoint, прийняти оплату і виконати видачу. Інструкція — `BOT_INTEGRATION.md`.

Коду вашого бота та платіжної інтеграції в початковому архіві немає. Вони не були вигадані або підмінені успішною оплатою. До підключення бота оформлення показує зрозуміле повідомлення. Прямий перехід на маркет для «покупки» прибрано: він не стягував би вашу націнку.

Перевірене замовлення діє 15 хвилин. Воно не резервує товар і не означає, що оплата виконана. Redis зберігає запис добу для повторних запитів; після 15 хвилин endpoint бота повертає `410`.

## Локальний перегляд

Python 3.12, додаткові Python-пакети не потрібні.

```bash
cp .env.example .env
# Для демо встановіть DEMO_MODE=1 у .env.
python server.py
```

Відкрийте `http://localhost:8080/uk/`. У демо всі товари й курси умовні, покупки вимкнені. У реальному режимі потрібен `LZT_TOKEN`. Локально без Redis замовлення зберігаються у SQLite; на Vercel цей fallback заборонений.

## Структура

```text
api/gateway.py          — точка входу Vercel Function
server.py               — API, LolzTeam, перевірка кошика, Telegram auth
pricing.py              — курси, націнка, округлення, фільтри
store.py                — Upstash REST і локальне сховище для розробки
core.py                 — тип помилок API
vercel.json             — маршрутизація, static output, заголовки
public/                 — тільки публічні файли мініаппу
public/uk|ru|en/        — мова через URL
.env.example            — шаблон серверних змінних
tests/test_server.py    — тести розрахунків і замовлень
```

## Перевірки та межі перевірки

```bash
python -m unittest discover -s tests -v
```

Перевірені на фікстурах: +20%, обидві валюти, округлення, конвертація фільтрів, підміна суми, зміна ціни, проданий товар, дублікати, повторне оформлення, Redis SET NX, відсутність SQLite на Vercel, Telegram HMAC та маршрут Vercel gateway. У Chromium перевірені кошик, збереження, перемикання валют, локалі та ширини 320–1440 px; виклики Telegram перевірені на тестовому SDK.

Живі LZT-запити з вашим токеном, реальна база Upstash, оплата в боті й публічний Vercel deployment не перевірялися — доступи не надавалися. Адаптер LZT працює за документованими endpoint; перед прийомом оплати перевірте фактичний формат цін/характеристик вашого API-акаунта.

Пам'ятайте про ліміти запитів: локальний throttling працює в межах інстансу. Для значного публічного трафіку налаштуйте rate limit у Vercel Firewall. Максимальна тривалість API-функції — 60 секунд; перевірка кошика виконується до 5 паралельних запитів.
